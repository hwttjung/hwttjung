# 14개 매체 사이트별 고유 테마 및 카테고리 정보 일람표

본 문서는 기사 생성 파이프라인에서 작동하는 14개 송출 대상 매체 사이트의 **고유 테마(Theme) 지침**과 **카테고리(Category) 리스트** 정보를 총망라하여 정리한 공식 매뉴얼입니다.
